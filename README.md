Langkah-langkah dalam menjalankan program yang kami buat :
  1. Cara pertama menggunakan ekstension live server pada VSCode
    1. masuk ke workspace direktory
    2. kemudian lakukan git clone di workspace direktory
    3. open folder ./dist pada folder-folder yang telah di clone di VSCode 
    4. unduh ekstension live server
    5. arahkan kursor ke file ./dist/index.html kemudian klik kanan dan pilih opsi jalankan dengan Open with Live Server
  2. Cara kedua dengan menggunakan Python
    1. masuk ke workspce direktory
    2. kemudian lakukan git clone di workspace direktory
    3. open folder ./dist pada folder-folder yang telah di clone di VSCode
    4. pada terminal lakukan cd ./dist
    5. kemudian pada direktory ~/dist pada terminal ketik command berikut : python3 -m http.server 8080
    6. kemudian pergi ke browser, masuk ke kolom search dan cari http://localhost:8080/
