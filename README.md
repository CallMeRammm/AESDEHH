Beberapa cara untuk menjalankan program kami : 
Cara pertama dengan menggunakan extension live-server di VSCode
1. Clone repository ini kedalam folder kosong
2. Buka VSCode
3. Masuk kedalam folder yang telah berisi program kami
4. Download dan install extension live server di VSCode
5. Setelah di install, klik kanan pada file index html (didalam folder dist)
6. Pilih opsi Open with Live Server

Cara kedua dengan menggunakan python server
1. cara ini memerlukan python, sehingga jika belum memiliki sebaiknya install terlebih dahulu
2. Lakukan git clone ke folder kosong
3. Buka VSCode dan pindah ke folder yang telah berisi program kami
4. Buka terminal di VSCode
5. Lakukan change direktory ke folder /dist
6. Jalankan python server dengan command berikut : python3 -m http.server 8080
7. Buka Browser apa saja
8. masuk ke http://localhost:8080/
